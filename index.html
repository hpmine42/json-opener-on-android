JSON Opener

        
Open JSON files instantly from the Android share menu — no import, no upload. Everything stays on your device.


        

          PWAOfflinePrivateOpen source
        


        
Install on Android

        
    
          
  1. Open this page in Chrome on your Android device.
    2. 
          
  2. Tap ⋮ → Install app (or “Add to Home screen”).
    3. 
          
  3. You'll see the { } icon on your home screen and in the share sheet for .json files.
    4. 
        


        
How to open a JSON file

        
    
          
  1. Tap Share on the file (in Files, Gmail, Drive, etc.).
    2. 
          
  2. Choose JSON Opener from the share menu.
    3. 
          
  3. The file opens instantly in the app.
    4. 
        


        
What you can do in the app

        
    
          
  • Tree view — expand & collapse objects/arrays, virtualized for huge files
    • 
          
  • Search — keys, values & paths (Ctrl+F / /), regex & filter mode
    • 
          
  • Text view — pretty/minified with syntax highlighting & line numbers
    • 
          
  • Table view — ideal for arrays of objects (like spreadsheets)
    • 
          
  • Schema & Stats — structure, types, depth & size insights
    • 
          
  • Tools — validate, format, sort, YAML/CSV, JSONPath, flatten & diff
    • 
          
  • Share / Save / Copy — send to other apps, download or copy to clipboard
    • 
          
  • Offline — works without internet after first load
    •

Privacy

        
No data is uploaded. Everything runs locally in your browser. Large files (many MB) are parsed locally; the tree stays fluid thanks to virtualization. Recent files list is stored only in localStorage on your device.
