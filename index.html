JSON Opener

        
Opens JSON files directly from the Android share sheet — no import, no upload. Everything stays on your device.


        
Install

        
    
          
  1. Open this page in Chrome on your Android device.
    2. 
          
  2. Tap ⋮ → “Install app” (or “Add to Home screen”).
    3. 
          
  3. The app appears with the { } icon on your home screen.
    4. 
        


        
Open a JSON file

        
    
          
  1. In another app, tap Share on the file.
    2. 
          
  2. Choose JSON Opener in the share sheet.
    3. 
          
  3. The file opens immediately.
    4. 
        

        
You can also choose a file, drop one onto the page, or paste JSON from the clipboard.


        
In the app

        
    
          
  • ✓ Tree view — expand and collapse objects & arrays
    • 
          
  • ✓ Table view — arrays of objects as a spreadsheet
    • 
          
  • ✓ Search — keys and values (Ctrl/Cmd+F or /)
    • 
          
  • ✓ Raw JSON — pretty or minified, with highlighting
    • 
          
  • ✓ Copy path — long-press a node for path, value, or JSON
    • 
          
  • ✓ Share / Save / Copy — send the file to other apps
    • 
          
  • ✓ Schema & stats — structure, types, and depth
    • 
          
  • ✓ Recent files — reopen what you viewed last
    • 
          
  • ✓ Dark & light — plus offline support

Keyboard shortcuts

        
    
          
  • CtrlF or / Search
    • 
          
  • T Tree view · R Raw view · L Table view
    • 
          
  • E Expand all · C Collapse all
    • 
          
  • ↑ ↓ ← → Navigate the tree
    • 
          
  • CtrlV Paste JSON on the home screen
    • 
          
  • ? This help · Esc Close panels

Privacy

        
All data stays on your device. Nothing is uploaded.

        Large files (several MB) are rendered with a virtualized tree so scrolling stays smooth.
