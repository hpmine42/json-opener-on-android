About

        
JSON Opener

        
A local studio for JSON. Open files from the Android share sheet — no import, no upload.


        

          PWA
          Offline
          Private
        


        
Install on Android

        
    
          
  1. Open this page in Chrome.
    2. 
          
  2. Tap ⋮ → Install app.
    3. 
          
  3. The app appears on the home screen and in the share sheet.
    4. 
        


        
Open a file

        
    
          
  1. Tap Share on a JSON file.
    2. 
          
  2. Choose JSON Opener.
    3. 
          
  3. It opens here, on-device.
    4. 
        


        
Workspace

        
    
          
  • Tree — virtualized expand/collapse, copy path or value
    • 
          
  • Search — keys, values, paths; regex and filter
    • 
          
  • Text — pretty or minified, with highlighting
    • 
          
  • Table — arrays of objects as a spreadsheet
    • 
          
  • Schema & stats — types, depth, distribution
    • 
          
  • Tools — validate, YAML, CSV, JSONPath, flatten
